      AI

      Access codeOnly for a hosted Ice Cream Edition whose owner protected the AI. Ask them for it.
      API keyNot needed when the site provides the AI. Saved only in this browser, so don't save it on a shared or school computer.
      Model
      API addressDefault: https://api.experientiallabs.ai/v1. Any OpenAI-compatible endpoint works; the base or the full /chat/completions address are both fine.
      CreativityLower is more focused, higher is more varied.
      Longest reply
      ReasoningHow long the model thinks before answering, if it supports it. More is smarter but slower.
      Coding: longest replyUsed when you ask for code, a game or a file. Thinking counts toward this too.
      Coding: reasoningLess thinking leaves more room for the code itself. If a reply still gets cut off mid-file, it continues by itself.
      Custom instructionsAdded to every chat, e.g. "I'm in 10th grade. Keep answers short."
      Text size in chats
      Enter sends the messageOff: Ctrl+Enter sends, Enter adds a line.
      Stream repliesShow the answer as it's written.
      Render mathShows equations like $x^2$ as formatted math.
      Show the model's thinkingFor reasoning models that share their steps.
      Save chat historyOff: chats disappear when you close the page.

      Data and privacy

      Everything stays in this browser: favorites, recent games, chats and settings. Nothing is uploaded except your chat messages, which go to the AI provider.

      About

      Ice Cream Edition is a fan-made hub for study breaks. Games, game hosting and thumbnails come from The Pizza Edition and each game's developers. More games from GameMonetize and GameDistribution. The AI runs through your own API key (Experiential Labs by default, model deepseek-v4.1-flash). Formatting by marked, DOMPurify and KaTeX. Icons partly from Lucide. Licenses are in the vendor folder.
